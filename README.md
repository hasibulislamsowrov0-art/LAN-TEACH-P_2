## 🔄 Cross-Tab Real-time Synchronization
Changes made in `admin.html` (such as approving a plot, updating a user's password, changing a username, or editing site settings) immediately trigger a `geoterra-data-synced` event across all open browser tabs, allowing seamless live updates without requiring manual page refreshes.
